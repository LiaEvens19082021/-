# Руководство: Запуск проекта в Visual Studio (.NET 8 + pgAdmin 4 / PostgreSQL)

Этот проект полностью настроен для работы на **.NET 8 (C# 12)** **БЕЗ установки Node.js**! Вам потребуется только **Microsoft Visual Studio 2022** (версии 17.8+) с поддержкой **.NET 8.0 Desktop** и (при необходимости сохранения в БД) установленный **PostgreSQL + pgAdmin 4**.

---

## 🚀 Шаг 1. Запуск в Visual Studio (.NET 8 Windows Desktop)

1. **Откройте решение**:
   - Дважды кликните по файлу **`ShiftScheduleApp.sln`** в папке проекта.
   - Либо откройте Visual Studio: **Файл → Открыть → Проект или решение...** и укажите `ShiftScheduleApp.sln`.
   - Visual Studio автоматически восстановит пакет **Npgsql 8.0.5** (драйвер PostgreSQL для .NET 8).

2. **Нажмите Запуск**:
   - В верхней панели Visual Studio нажмите зелёную стрелку **▶ Запуск** (или клавишу **`F5`**).
   - Программа откроется сразу (даже если база данных ещё не подключена — в локальном демо-режиме).

---

## 🗄️ Шаг 2. Как добавить и подключить базу данных из pgAdmin 4

1. **Создайте базу данных в pgAdmin 4**:
   - Откройте **pgAdmin 4** на вашем компьютере.
   - В дереве слева разверните **Servers → PostgreSQL → Databases**.
   - Нажмите правой кнопкой по **Databases → Create → Database...**
   - Введите имя базы, например: `shift_schedule` и нажмите **Save**.

2. **Подключите базу прямо в приложении**:
   - В запущенной программе (в нижней панели) нажмите кнопку **`🗄️ База PostgreSQL (pgAdmin 4)`**.
   - Введите параметры подключения:
     - **Сервер (Host)**: `localhost`
     - **Порт**: `5432`
     - **Имя базы данных**: `shift_schedule`
     - **Пользователь**: `postgres`
     - **Пароль**: ваш пароль от PostgreSQL, который вы задавали при установке
   - Нажмите **«Подключить и создать таблицы»**.
   - Программа **сама создаст** нужные таблицы `employees` и `shift_overrides` и загрузит туда сотрудников!
   - После этого вы сразу сможете видеть и редактировать эти таблицы в pgAdmin 4 (**Schemas → public → Tables**).

3. *(По желанию)* Вы также можете вручную открыть файл **`csharp/schema_pgadmin4.sql`** через **Query Tool** в pgAdmin 4.

## 📁 Структура решения (.NET 8)

- **`ShiftScheduleApp.sln`** — Главный файл решения Microsoft Visual Studio.
- **`csharp/ShiftScheduleCSharp.csproj`** — Проект Windows Desktop на **.NET 8 (`net8.0-windows`, C# 12)** с подключённым драйвером **Npgsql**.
- **`csharp/DatabaseService.cs`** — Сервис подключения и сохранения сотрудников/телефонов/смен в **PostgreSQL (pgAdmin 4)** (настройки сохраняются в `db_config.json`).
- **`csharp/schema_pgadmin4.sql`** — SQL-скрипт структуры таблиц для **pgAdmin 4**.
- **`csharp/MainForm.cs`** — Графический интерфейс Windows (табель, ведомость, добавление/удаление сотрудников, телефон, декрет, юбиляры 50+, настройка БД).
- **`csharp/Models.cs`** — Модели и расчёт графиков 2/2, 5/2, 1/3, 3/3, отпусков, больничных, декрета и юбилеев.
- **`standalone_offline.html`** — Автономный файл для браузера без Node.js.
