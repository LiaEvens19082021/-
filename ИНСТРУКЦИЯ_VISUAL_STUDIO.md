# Руководство: Запуск проекта в Visual Studio БЕЗ Node.js

Этот проект полностью настроен для работы **БЕЗ установки Node.js**! Вам потребуется только **Microsoft Visual Studio** (2017, 2019 или 2022) с поддержкой C#.

---

## 🚀 Способ 1. Запуск в Visual Studio (C# 7.3 Windows Desktop) — БЕЗ Node.js

1. **Откройте решение**:
   - Дважды кликните по файлу **`ShiftScheduleApp.sln`** в папке проекта.
   - Либо откройте Visual Studio: **Файл → Открыть → Проект или решение...** и укажите `ShiftScheduleApp.sln`.

2. **Нажмите Запуск**:
   - В верхней панели Visual Studio нажмите зелёную стрелку **▶ Запуск** (или клавишу **`F5`**).
   - Visual Studio сама скомпилирует проект на C# и откроет графическое Windows-окно программы.
   - **Устанавливать Node.js, npm или что-либо ещё НЕ требуется!**

3. **Что умеет программа на C# Windows**:
   - 📅 **Табель смен (Матрица месяца)**: наглядная сетка по дням с цветовой подсветкой (Р — работа, В — выходной, ВР — внеплановая смена, ВВ — внеплановый отгул, Б — больничный, ОТ — отпуск).
   - 🖱️ **Редактирование смен**: двойной клик по любой ячейке дня позволяет назначить замену, больничный, отпуск или отгул.
   - 💰 **Автоматический расчёт зарплаты**: учитывает отработанные смены, дневную ставку каждого сотрудника, пособие по больничному листу (80%), компенсацию за отпуск (100%) и персональные премии.
   - ✏️ **Изменение дневной ставки**: возможность в 1 клик поменять ставку за 1 день с автоматическим пересчётом итоговой зарплаты.
   - 🖨️ **Расчётный листок**: подробная детализация начислений по сотруднику.
   - 📊 **Экспорт в Excel (CSV)**: сохранение ведомости в таблицу одним нажатием кнопки.

## 🌐 Способ 2. Автономная веб-версия в браузере — БЕЗ Node.js

Если вы хотите открыть красивый интерфейс прямо в браузере (Chrome, Edge, Яндекс), но без Node.js:
1. Найдите в папке проекта файл:
   👉 **`standalone_offline.html`**
2. Просто дважды щёлкните по нему мышью.
3. Он мгновенно откроется в вашем браузере как полноценный сайт с табелем, расчётом зарплаты и экспортом в Excel. Никаких серверов или Node.js не нужно!

## 📁 Структура решения

- **`ShiftScheduleApp.sln`** — Главный файл решения Microsoft Visual Studio.
- **`csharp/ShiftScheduleCSharp.csproj`** — Проект Windows Desktop на C# 7.3 (.NET 7.0 Windows).
- **`csharp/MainForm.cs`** — Графический интерфейс Windows с таблицами, матрицей и ведомостью.
- **`csharp/Models.cs`** — Алгоритмы расчёта графиков 2/2, 5/2, 1/3, 3/3, ставок, отпусков и больничных.
- **`standalone_offline.html`** — Автономный файл для браузера без Node.js.
