# Руководство: Как открыть и запустить проект в Visual Studio

В этом репозитории уже подготовлены все файлы решений и проектов для **Microsoft Visual Studio 2022 / 2019** и **Visual Studio Code**.

---

## ⚡ Быстрый запуск в 1 клик на Windows (без настроек)

1. Убедитесь, что на компьютере установлен **Node.js** (бесплатная LTS версия с официального сайта: [nodejs.org](https://nodejs.org/)).
2. Просто дважды кликните по файлу:
   👉 **`START_PROJECT_WINDOWS.bat`**
3. Скрипт сам проверит библиотеки, запустит сервер и автоматически откроет в браузере визуальный интерфейс приложения: `http://localhost:3000`.

---

## 🚀 Способ 1. Запуск через Microsoft Visual Studio 2022

1. **Открытие проекта**:
   - Дважды кликните по файлу **`ShiftScheduleApp.sln`** в корне папки.
   - Либо откройте Visual Studio, выберите **Файл** → **Открыть** → **Проект или решение...** и выберите `ShiftScheduleApp.sln`.

2. **Структура в «Обозревателе решений» (Solution Explorer)**:
   - **`ShiftScheduleApp`** — Веб-приложение с визуальным интерфейсом (React + TypeScript + Tailwind CSS).
   - **`ShiftScheduleCSharp`** — Нативная программа на C# .NET 8.0 с консольным интерфейсом и полным алгоритмом расчёта смен и зарплаты.

3. **Запуск веб-интерфейса (F5)**:
   - В выпадающем списке проектов выберите **`ShiftScheduleApp`**.
   - Нажмите зелёную кнопку **▶ Запуск** (или клавишу **`F5`**).
   - Visual Studio автоматически выполнит `npm run dev` и откроет страницу `http://localhost:3000` в браузере!

4. **Запуск проекта C#**:
   - Щёлкните правой кнопкой мыши по проекту **`ShiftScheduleCSharp`** → **Назначить запускаемым проектом** (Set as Startup Project).
   - Нажмите **▶ Запуск (F5)**.
   - Откроется интерактивная программа на C# с табелем смен, расчётом зарплаты и меню на русском языке.

---

## 💻 Способ 2. Запуск через Visual Studio Code

1. Откройте Visual Studio Code.
2. Выберите **Файл** → **Открыть папку...** (Open Folder) и укажите папку проекта.
3. Нажмите клавишу **`F5`** (уже настроен файл `.vscode/launch.json`).
4. Либо откройте встроенный терминал (клавиши `Ctrl + ~`) и выполните:
   ```bash
   npm install
   npm run dev
   ```
5. Откройте в браузере: `http://localhost:3000`.

---

## 📋 Системные требования

- **Операционная система**: Windows 10/11, macOS или Linux.
- **Node.js**: Версия 18, 20 или 22+ (скачивается с [nodejs.org](https://nodejs.org/)).
- **Visual Studio**: Visual Studio 2022 (Community / Professional) с установленным компонентом «Разработка Node.js» или Visual Studio Code.
- Для сборки C# проекта: **.NET SDK 8.0** или 9.0 (входит в стандартную установку Visual Studio 2022).
